# Catalog schema

Each product in `app.js` has:

- `id`
- `name`
- `team`
- `season`
- `category`
- `price`
- `custom`
- `new`
- `image`

Current categories used by the storefront: `Current Kits`, `Retro`, `National Teams`, and `MLS`.

The storefront intentionally has no Leagues section or League navigation.
